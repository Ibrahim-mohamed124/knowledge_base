Concepts

  • The Parsec appliance acts as a client to existing storage devices using a Layer 2 or Layer 3 connection. By using a combination of high-end hardware and software, to make verified copies of data from the source storage device to the desired destination storage device.
  • Data mobility can be inter-site by single appliance, or cross-sites by more than one parsec appliance.

Connection Points to a Storage Environment:

Point 1     Initial State: Hosts are accessing shares/LUNs on the source storage (NAS/SAN).
Point 2     Connect the Appliance to the network/fabric and configure access to both migration
                   sources and targets shares/LUNs.
Point 3     Configure and start/schedule the migrations from sources to targets shares/LUNs.
Point 4    Upon successful completion and validation of each migration, unmount/unmap the
                   original shares/LUNs from sources storage, and mount/map the shares/LUNs from targets storage.
