Cluster Architecture on OCI

  • OCI provide DNS resolution service which is used by OCP > OCI DNS
  • The compute nodes reside in Virtual Cloud Network VCNs
    1. Public subnet has external load balancer that route the traffic to the master and worker nodes
    2. Private subnet has internal load balancer that the master nodes use to communicate

 

Installation Options
  1. Assisted
  1. Agent  
    • an OCI-provided Terraform script or configure the resources manually if you need advanced customizations or work in a disconnected (offline) environment.

OCI Resource Manager is Oracle Cloud Infrastructure's fully managed Infrastructure as Code (IaC) service.

It allows you to automate the provisioning, updating, and destroying of cloud infrastructure using HashiCorp Terraform without having to manage Terraform state files, backend storage, or execution environments yourself.
