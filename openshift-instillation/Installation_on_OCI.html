OCI Resource Manager is Oracle Cloud Infrastructure's fully managed Infrastructure as Code (IaC) service.

It allows you to automate the provisioning, updating, and destroying of cloud infrastructure using HashiCorp Terraform without having to manage Terraform state files, backend storage, or execution environments yourself.

In Oracle Cloud Infrastructure (OCI), a shape is simply the hardware profile or template that determines the capacity of a compute instance.

Autoscaling Compute Nodes

To use autoscaling, you'll need to create a worker image and upload it to Object Storage. You can enable autoscaling by either:

  • Creating a new OpenShift cluster on OCI with autoscaling enabled. This is useful when elastic worker capacity should be part of the cluster from the beginning.
  • Adding autoscaling to an existing OpenShift cluster, by deploying an Autoscaling Operator stack. This is useful for teams that already run OpenShift on OCI and want to introduce autoscaling without rebuilding the cluster.

Autoscaling workers use a Red Hat Enterprise Linux CoreOS (RHCOS) image that matches the OpenShift cluster version. You'll download the matching RHCOS OpenStack qcow2 image, upload it to OCI Object Storage, and provide a read pre-authenticated request URL to the Terraform stack. For VM-based autoscaling, the downloaded qcow2 image can be used directly. For bare metal autoscaling, the image must be prepared with iSCSI boot configuration before upload. A helper script is provided in the OCI OpenShift quickstart repository and should be run from a Linux host or Linux VM.

Prerequisites 

Before installing an OpenShift cluster on OCI, download and run the create-resource-attribution-tags stack from the OpenShift on OCI Releases page on GitHub. This stack creates a tag namespace defined-tags (openshift-tags)and and defined tags (openshift-resource) required which are used to tag OpenShift resources. These are required before using other Terraform stacks.

To make changes to the manifests or Terraform code, you can clone the oracle-quickstart / oci-openshift GitHub repository and access the custom_manifests and terraform-stacks directories directly. Review the documentation in the repository and generate new Terraform stack zip files by running the make command.
